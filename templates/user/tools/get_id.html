Công cụ lấy ID bài viết

Chuyển đổi đường dẫn (link) bài viết thành ID số để sử dụng trong việc tạo nhiệm vụ. Nhanh chóng và chính xác.

Ví dụ: https://www.facebook.com/photo/?fbid=123456...

Lấy ID thành công!

Hướng dẫn sử dụng

  • 1
    Mở ứng dụng hoặc trang web chứa bài viết bạn muốn thao tác (VD: Facebook, TikTok...).
  • 2
    Tìm nút Chia sẻ (Share) ở bài viết và chọn Sao chép liên kết (Copy link).
  • 3
    Dán liên kết vừa sao chép vào ô "Đường dẫn bài viết" ở phía trên và nhấn nút Lấy ID ngay.
  • 4
    Hệ thống sẽ phân tích và trả về dãy số ID tương ứng. Bạn nhấn Sao chép ID để sử dụng ID này khi tạo nhiệm vụ.
